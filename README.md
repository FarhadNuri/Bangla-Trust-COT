# BanglaTrust-CoT

Trust Calibration in Chain-of-Thought Reasoning: A Low-Resource-Language HCI Study Using Bangla Riddles.

A research web application exploring trust calibration, reliance, and flaw detection in step-by-step reasoning (Chain-of-Thought) across Bangla and English riddles.

For design, specifications, and architecture, see the `docs/` folder:
- `docs/01_PROJECT_ANALYSIS.md`
- `docs/02_ARCHITECTURE.md`
- `docs/03_API_CONTRACT.md`
- `docs/04_DATABASE.md`

## Commands

- **Development server:** `npm run dev`
- **Run tests:** `npm run test`
- **Validate stimulus dataset:** `npm run validate:stimuli`
- **Run end-to-end smoke test:** `npm run smoke`
